# Reclaim

Helps adult survivors of non-consensual intimate imagery (real or AI deepfake) enforce the TAKE IT DOWN Act's 48-hour removal duty. It works with links only and never touches images.

**Not legal advice. Reclaim prepares requests you send.**

## Run locally

```bash
npm install
cp env.example .env.local   # add GEMINI_API_KEY; DEMO_MODE=true seeds the fictional "Jordan Ellis" case
npm run dev
```

In demo mode, press **Shift+D** to open the presenter controls. Press **Esc** on any screen to quick-exit.

Full setup, Cloud Run and Cloud Scheduler docs arrive in build step 8.
